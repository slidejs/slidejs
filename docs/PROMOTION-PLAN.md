# Slide DSL 推广计划

> **基于 Jeremy Howard 的实用主义教育哲学**  
> "先看结果，再学原理" - 让用户快速看到价值，然后深入学习

## 📋 执行摘要

本计划采用"自上而下学习"和"快速迭代"策略，优先实施能够快速见效的推广行动。所有行动都遵循"实用优先"原则，让用户能在 5 分钟内看到 Slide DSL 的价值。

## 🎯 核心目标

1. **降低学习门槛**：让非技术用户也能在 5 分钟内创建第一个幻灯片
2. **展示实用价值**：通过真实案例展示 Slide DSL 解决的实际问题
3. **建立社区**：通过 Show & Tell 形成自传播循环
4. **快速验证**：每个推广行动都要能快速验证效果
